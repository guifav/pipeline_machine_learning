# Frontend - Flight Delay Predictor

Interface web moderna construída com React + TypeScript + Vite para previsão de atrasos de voos.

## Instalação

```bash
cd app/frontend
npm install
```

## Executar

```bash
npm run dev
```

Aplicação disponível em: `http://localhost:5173`

## Build

```bash
npm run build
npm run preview
```

## Conectar com API

Certifique-se que o backend está rodando em `http://localhost:8000`

## Features

- Formulário interativo com validação
- Previsão em tempo real
- Resultados visuais com status, probabilidade e tempo estimado
- Design responsivo moderno
